# MakeMyLook.Ai

MakeMyLook.Ai is a unisex AI-assisted beauty and personal-grooming web
application. It helps users explore personalized beauty and grooming
recommendations using saved preferences, skin analysis, and
outfit-colour analysis.

> **Project status:** The React/Vite frontend production build and the
> skin/outfit analysis API endpoints have been tested successfully. The
> current analysis uses rule-based computer-vision heuristics; it is not
> a trained deep-learning model. The Before & After screen is a preview
> interface and does not yet generate a transformed photograph.

## Features

-   User welcome, login, and registration screens (frontend flow).
-   Personal beauty profile with gender, style preference, skin concern,
    hair type, and hair length.
-   Saved profile preferences in browser `localStorage`.
-   Manual skin-tone selection.
-   Skin-photo analysis through the backend.
-   Outfit-photo colour analysis through the backend.
-   Personalized beauty and grooming recommendation pages.
-   Gender-aware recommendation categories.
-   Before & After preview interface.
-   Profile preference editing and Sign Out navigation.

## Technology stack

### Frontend

-   React

## Prerequisites

-   Node.js and npm
-   Python 3
-   Windows PowerShell (commands below use PowerShell)

## Run the frontend

Open PowerShell in the project root and run:

``` powershell
cd frontend
npm install
npm run dev
```

Open the local URL printed by Vite (typically `http://localhost:5173/`).

To create a production build:

``` powershell
npm run build
```

The generated production files are placed in `frontend/dist/`.

## Run the backend

Open a **separate** PowerShell terminal in the project root:

``` powershell
cd backend
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Start the FastAPI server using the Python module that defines the
FastAPI `app` object. For example, **if that file is `main.py`**, run:

``` powershell
python -m uvicorn app.main:app --app-dir backend --reload
```

If the application entry file has a different name or is inside a
package, adjust the Uvicorn import path to match it. Keep the backend
running in its own terminal.

## Backend verification

When the backend is running on port `8000`, use:

-   Health endpoint: `http://127.0.0.1:8000/health`
-   Interactive API documentation: `http://127.0.0.1:8000/docs`

Analysis endpoints tested during development:

-   `POST /api/skin/analyze` --- accepts a skin/face image for heuristic
    skin analysis.
-   `POST /api/outfit/analyze` --- accepts an outfit image for colour
    analysis.

Use the Swagger documentation at `/docs` to check the required upload
field names and test requests.

## Saved profile preferences

The profile is saved in browser storage under:

``` text
makemylook_beauty_profile
```

The profile-save flow returns the user to Home. The Sign Out button
redirects to the Welcome screen and intentionally does not delete saved
beauty preferences.

## Known limitations

-   The login/register flow is frontend-only; credentials are not
    verified by a backend authentication service.
-   Sign Out currently navigates to Welcome but does not invalidate a
    secure server-side session.
-   Skin and outfit analysis use rule-based/computer-vision heuristics
    rather than a trained deep-learning model.
-   The Before & After page is a preview interface; actual AI image
    transformation is not connected yet.
-   Results can vary with lighting, image quality, camera angle, and the
    contents of an uploaded image.

## Privacy and image handling

Use images only with appropriate permission. Avoid uploading sensitive
images when testing. Review the backend implementation before deployment
to confirm whether uploaded images are stored, how long they are
retained, and what access controls apply.
